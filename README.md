# \# 🐕 12-DOF Quadruped Robot (Hardware Prototyping)

# 

# \## 📌 Project Overview

# This repository documents the mechanical assembly, power system integration, and structural evaluation of a 12-Degree-of-Freedom (DOF) quadruped robot. The project focuses heavily on hardware integration, kinematics testing, and identifying mechanical constraints in open-source 3D models.

# 

# \*(Note: The initial testing firmware is currently being refactored. This repository serves primarily as a hardware and mechanical design portfolio).\*

# \## 🛠️ Bill of Materials (BOM)

# \- \*\*Microcontroller:\*\* ESP32 DevKit

# \- \*\*Servo Controller:\*\* 16-channel PWM Servo Driver (PCA9685/TCA)

# \- \*\*Actuators:\*\* 12 x MG996R High-Torque Servos

# \- \*\*Custom Power System:\*\* 

# &#x20; - Custom-built 3S Li-ion Battery Pack

# &#x20; - High-power 12V/20A DC-DC Buck Converter (to ensure stable current for 12 simultaneous servo movements).

# 

# \## ⚠️ Engineering Challenges \& Structural Evaluation

# During the physical assembly and initial testing, a critical engineering challenge was identified regarding the open-source 3D printed structural parts:

# \- \*\*Mechanical Flaws:\*\* The downloaded 3D models lacked the structural rigidity required to support the combined weight of the custom power supply and the torque generated by the 12 MG996R servos.

# \- \*\*Outcome:\*\* The physical stress led to mechanical failures at the joints. The project was temporarily disassembled for a complete mechanical redesign.

# \- \*\*Next Steps:\*\* Currently redesigning custom, reinforced joint brackets using Autodesk Fusion to handle high-stress loads before rewriting the Inverse Kinematics (IK) algorithm.
